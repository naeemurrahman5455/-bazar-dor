## 🛒 BazarDor — Bangladesh Market Price Tracker

### Making everyday market prices accessible to everyone in Bangladesh.

BazarDor is a modern, responsive web application that helps users explore the prices of essential daily commodities in Bangladesh. Users can track price changes, browse products by category, compare prices across different markets, and make informed shopping decisions through a user-friendly interface.


## ✨ Key Features

- 📊 Daily Market Prices: Browse the latest available prices of essential commodities, including rice, lentils, oil, vegetables, and other everyday products.

- 📈 Price Change Tracking: Identify products with rising or falling prices and view percentage changes compared with previous prices.

- 🔍 Product Categories & Sorting: Explore products by category and organize product listings using sorting options.

- 🏪 Product Details & Market Comparison: View detailed product information, price ranges, and market-wise price comparisons.

- 🔐 Authentication & User Profile: Create an account, sign in securely, and access your user profile.

- 📱 Fully Responsive Design: Enjoy a consistent experience across mobile phones, tablets, and desktop devices.

- 🇧🇩 Bengali-Friendly Interface: Browse market information using Bengali text and localized number formatting.

- ⚡ Modern User Experience: Navigate a clean, accessible interface with reusable components and interactive notifications.

## 🚀 Getting Started

Follow these instructions to run BazarDor locally.

## Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

## Installation

## 1. Clone the repository

git clone <your-github-repository-url>

## 2. Navigate to the project directory

cd bazar-dor

## 3. Install dependencies

npm install

## 4. Configure environment variables

Create a .env.local file in the project root and add the required environment variables.

BACKEND_URL=your_backend_api_url

Configure any additional MongoDB and Better Auth environment variables required by your project. Never commit credentials, API secrets, or other sensitive environment variables to GitHub.

## 5. Start the development server

npm run dev

Open http://localhost:3000 in your browser.


## 📂 Project Highlights


- Built using the Next.js App Router.
- Organized with reusable React components.
- Integrates REST APIs for product and market price information.
- Includes user authentication and profile functionality.
- Uses responsive layouts for mobile, tablet, and desktop.
- Provides a Bengali-friendly interface for users in Bangladesh.

## 🎯 Project Objective

The primary objective of BazarDor is to make essential commodity price information easier to access and understand. By helping users track price fluctuations and compare prices across markets, the platform aims to support smarter shopping decisions and greater awareness of everyday living costs in Bangladesh.
